# 퇴직연금 월수익 계산기

`index.html`을 브라우저로 열면 바로 동작하는 단일 파일 계산기입니다. 외부에서 불러오는 것은 Google Fonts뿐입니다.

## 입력
- 적립금, 위험자산 비중(최대 70%), 목표 월수익, 주당 매매 횟수
- 가정: 위험자산 기대수익률·변동성, 안전자산 수익률, 월 추가 납입

## 계산
- 필요 월수익률 = 목표 월수익 ÷ 적립금. 연 환산은 단리(×12)와 복리((1+m)^12 − 1)로 보여 줍니다.
- 위험자산 필요 월수익률 = (목표 월수익 − 안전자산 월수익) ÷ 위험자산 금액
- 거래 1회당 필요 수익률 = (1 + 위험자산 필요 월수익률)^(1 / 월 매매 횟수) − 1. 월 매매 횟수는 주당 횟수 × 52 ÷ 12입니다.
- 한 달 수익이 목표 이상일 확률: 위험자산 월수익률이 정규분포를 따른다고 가정합니다. 이 가정은 극단적인 달을 과소평가합니다.
- 필요 원금 = 목표 월수익 × 12 ÷ 계좌 기대수익률. 계좌 기대수익률은 위험 비중 × 위험자산 수익률 + 안전 비중 × 안전자산 수익률입니다.
- 필요 원금까지 걸리는 기간: 월 복리와 월 추가 납입을 반영합니다.
- 연금수령한도(1년차) = 적립금 ÷ (11 − 1) × 120%

수수료, 세금, 물가는 반영하지 않습니다. 일반 정보이며 투자 권유가 아닙니다.
